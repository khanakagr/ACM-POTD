### APPROACH
The task is to find the maximum number of `2 X 1` dominoes that can fit in an `m X n` board.

Each domino covers 2 squares, so the total number of dominoes is the total number of squares divided by 2. Since, only whole dominoes can be placed, the answer is `m*n / 2` using integer division.
